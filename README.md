# OUM SREE DEV — Personal Branding Website

Link : https://oum-sree-dev.vercel.app/

Premium multi-page personal branding website 

## Stack
- Next.js App Router
- TypeScript
- Framer Motion
- Lucide React
- CSS with responsive mobile layouts

## Routes
- `/` Home
- `/about` About
- `/brands` Brands
- `/brands/company-one` … `/brands/company-four`
- `/spirituality` Spirituality
- `/contact` Contact

## Notes
- White mode is the default, with a dark-mode toggle.


## Run
```bash
npm install
npm run dev
```
